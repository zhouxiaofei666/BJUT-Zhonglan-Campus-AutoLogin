# 北京工业大学中蓝公寓校园网自动登录

一个面向 **北京工业大学中蓝公寓校园网** 的 Android 自动 Portal 认证工具。

本项目不绑定特定手机型号，也不包含任何个人账号、手机号、密码、设备 MAC 或其他个人身份信息。首次安装后，由使用者自行输入校园网账号和密码；凭据仅加密保存在本机。

> 本项目为非官方开源工具，与北京工业大学及校园网运营方无隶属或官方授权关系。校园网认证接口如有调整，项目可能需要同步更新。

## 这个 App 是干什么的？

平时连接中蓝公寓校园 Wi-Fi 后，手机可能还需要打开网页完成一次校园网认证。

这个 App 做的事情很简单：

**连接校园 Wi-Fi → 检测是否已经联网 → 如果还没有认证 → 自动提交校园网账号和密码 → 完成登录。**

第一次设置好以后，正常情况下不需要每次再打开认证网页。

## 当前网络配置

以下参数来自中蓝公寓当前 Dr.COM / EPortal 认证环境，并作为项目固定网络配置保留：

- Server: `10.21.221.98:801`
- Path: `/eportal/portal/login`
- Method: `GET`
- Account suffix: `@campus`
- Client IPv4: 运行时从当前 Wi-Fi 动态读取
- MAC 参数: 使用 Portal 当前兼容值 `000000000000`
- Success: JSONP response contains `"result":1` 或认证成功提示

这些参数属于校园网认证流程，不是某一台手机的个人配置。

## 功能

- 连接 Wi-Fi 后监听网络状态
- 未通过 Portal 认证时自动尝试登录
- 支持手动“立即登录一次”
- 支持开机后恢复自动登录服务
- 校园网账号和密码通过 Android Keystore + AES/GCM 加密保存在本机
- 不上传凭据，不接入第三方服务器，不包含统计或追踪功能

## 兼容性

- Android 8.0（API 26）及以上
- 不依赖具体手机品牌或型号
- 不同 Android 厂商对后台服务、自启动和电池优化的限制不同；如果自动登录服务被系统停止，请在系统设置中允许本 App 后台运行/自启动，并将电池策略调整为允许持续运行

# 普通用户：从安装到使用

下面按顺序操作即可。

## 第 1 步：安装 APK

下载项目提供的 APK，然后在 Android 手机上安装。

如果系统提示“禁止安装未知来源应用”，按照系统提示临时允许当前浏览器或文件管理器安装 APK 即可。

安装完成后打开 App。

## 第 2 步：填写自己的校园网账号和密码

第一次打开 App 后：

1. 点击主界面右上角的 **⚙ 设置按钮**。
2. 在“校园网账号”中输入自己的校园网账号。
3. **不要输入 `@campus`**，App 会自动补上。
4. 在“校园网密码”中输入自己的校园网密码。
5. 点击 **“保存账号密码”**。
6. 看到“保存成功”后，点击 **“完成并返回”**。

例如你的校园网登录账号是：

```text
123456789@campus
```

那么 App 中只需要输入：

```text
123456789
```

密码正常输入自己的校园网密码即可。

> 每个人都需要填写自己的账号和密码。项目源码中没有作者的账号或密码。

## 第 3 步：连接中蓝公寓校园 Wi-Fi

先像平时一样，在手机系统中连接中蓝公寓的校园 Wi-Fi。

此时即使系统显示“已连接但无法访问互联网”也没关系，因为这通常说明 Wi-Fi 已经连上，但还没有完成 Portal 认证。

## 第 4 步：先手动测试一次

第一次使用建议先测试：

1. 回到 App 主界面。
2. 点击 **“立即登录一次”**。
3. 等待几秒。
4. 查看主界面的“当前状态”。

如果显示类似：

```text
✓ 校园网认证成功（10.x.x.x）
```

说明账号、密码和网络配置都正常。

这时可以直接打开浏览器测试是否已经能够访问互联网。

## 第 5 步：开启自动登录

手动测试成功后：

1. 在 App 主界面点击 **“开始自动登录”**。
2. 状态会变成 **“自动登录已开启”**。
3. 保持这个功能开启即可。

以后手机连接校园 Wi-Fi 时，App 会自动判断当前网络是否已经完成认证。

如果已经联网，App 不会重复登录；如果还没有完成 Portal 认证，App 会自动尝试认证。

## 第 6 步：允许通知

Android 13 及以上系统首次运行时可能会询问是否允许通知。

建议选择 **允许**。

这个通知用于保持校园网自动登录服务在后台运行，并显示当前登录状态。

## 第 7 步：设置后台运行

不同品牌手机的设置名称可能不同，但思路都是一样的。

进入：

```text
手机设置
→ 应用
→ 找到“北工大中蓝校园网自动登录”
```

然后尽量打开以下选项：

- 允许后台运行
- 允许自启动 / 开机启动（如果系统提供）
- 电池优化设为“不限制”或类似选项
- 不要手动禁止该 App 的后台活动

如果你的手机没有这些选项，不需要额外设置。

## 第 8 步：以后怎么用？

设置完成后，日常基本不需要再操作 App。

正常流程就是：

```text
手机连接中蓝公寓校园 Wi-Fi
        ↓
App 自动检测网络状态
        ↓
已经联网 → 什么也不做
        ↓
未认证 → 自动提交校园网登录
        ↓
认证成功 → 正常上网
```

## 临时不想自动登录怎么办？

打开 App，点击：

**“停止自动登录”**

即可停止后台自动认证。

以后需要时再点击：

**“开始自动登录”**

即可恢复。

## 修改校园网密码怎么办？

如果学校校园网密码修改了：

1. 打开 App。
2. 点击右上角 **⚙ 设置**。
3. 账号不需要修改时可以保留原账号。
4. 输入新的校园网密码。
5. 点击 **“保存账号密码”**。
6. 返回主界面后点击 **“立即登录一次”** 测试。

## 清除账号和密码

如果不再使用这个 App，或者准备把手机交给别人：

1. 打开 App。
2. 点击右上角 **⚙ 设置**。
3. 点击 **“清除已保存信息”**。

清除后，自动登录也会同时关闭。

# 常见问题

## 1. 点击“立即登录一次”后提示没有 Wi-Fi

先进入手机 Wi-Fi 设置，确认已经连接中蓝公寓校园 Wi-Fi，然后再返回 App 测试。

## 2. 提示“请先在 App 中保存账号和密码”

点击右上角 **⚙ 设置**，填写自己的校园网账号和密码并保存。

## 3. 提示当前不是目标校园内网

App 当前会检查手机获得的 IPv4 地址是否属于 `10.x.x.x` 校园内网。

请确认当前连接的是中蓝公寓校园网络，而不是手机热点、家庭 Wi-Fi 或其他网络。

## 4. 手动登录成功，但过一段时间自动登录失效

大多数情况下是 Android 系统关闭了后台服务。

请检查：

```text
手机设置
→ 应用
→ 北工大中蓝校园网自动登录
→ 电池 / 后台运行 / 自启动
```

尽量允许后台运行，并取消严格的电池限制。

## 5. 手机重启以后还需要重新设置吗？

账号和密码不需要重新填写。

如果之前已经开启“自动登录”，App 会尝试在开机后恢复后台服务。

部分 Android 手机会限制第三方 App 开机自启动，此时打开一次 App 即可恢复。

## 6. 为什么不直接判断 Wi-Fi 名称？

Android 新版本读取当前 Wi-Fi SSID 往往需要额外的位置权限。

当前版本不依赖具体手机型号，也不需要读取位置权限，而是通过 Wi-Fi 网络状态、当前 IPv4 地址以及校园网 Portal 服务器判断是否需要认证。

## 7. 会不会把我的校园网密码上传？

不会上传到开发者或第三方服务器。

账号和密码只保存在手机本机，并在需要登录校园网时发送给学校现有的 Portal 认证服务器。

## 隐私与安全

- 源代码中不包含真实校园网账号或真实密码。
- 每位用户的账号和密码只保存在自己的 Android 设备中。
- 本地凭据使用 Android Keystore 管理密钥，并通过 AES/GCM 加密保存。
- App 不读取或上传通讯录、短信、手机号、IMEI、Android ID 等设备身份信息。
- 登录时使用当前 Wi-Fi 获得的 IPv4 地址完成学校 Portal 认证。

需要注意：学校当前 Portal 接口使用 `HTTP` 而不是 `HTTPS`，因此即使 App 在本机安全保存密码，实际认证请求仍需遵循现有校园网协议，通过 HTTP 发送到校园内网认证服务器。

# 开发者：如何自己编译

## 方法一：GitHub Actions 编译

仓库包含：

```text
.github/workflows/build-apk.yml
```

推送代码后 GitHub Actions 会自动执行 Android 构建。

构建成功后：

1. 打开仓库的 **Actions** 页面。
2. 点击最新一次成功的 **Build Android APK**。
3. 滚动到页面底部的 **Artifacts**。
4. 下载：

```text
BJUT-Zhonglan-Campus-AutoLogin-APK
```

5. 解压后得到：

```text
app-debug.apk
```

## 方法二：本地编译

建议环境：

- JDK 17
- Gradle 8.7
- Android compileSdk 34

在项目根目录执行：

```bash
gradle :app:assembleDebug
```

编译完成后 APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```
